# Student Management System

## Project Description
This is a simple C++ Student Management System developed using Object-Oriented Programming (OOP) concepts. It stores student details, validates marks, allows re-evaluation of marks, and displays student results.

## Features
- Stores details of three students.
- Validates marks between 0 and 100.
- Rejects invalid marks.
- Allows updating student marks.
- Displays student details.
- Calculates Pass or Fail status (Pass mark: 40).

## OOP Concepts Used
1. Class and Objects
2. Private Data Members
3. Public Member Functions
4. Parameterized Constructor
5. Array of Objects
6. Function Accepting an Object

## Technologies Used
- Programming Language: C++
- Header Files: iostream, string

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Compile the program:

   `g++ main.cpp -o main`

4. Run the program:

   `./main`
